# KruSmart - ប្រព័ន្ធជំនួយការគ្រូបង្រៀនឌីជីថល (Teacher Digital Assistant System)

ប្រព័ន្ធគ្រប់គ្រងការងារបង្រៀន និងព័ត៌មានសិស្សឌីជីថល ដែលត្រូវបានរចនាឡើងយ៉ាងពិសេសផ្អែកលើស្តង់ដារក្រសួងអប់រំ យុវជន និងកីឡា សម្រាប់លោកគ្រូអ្នកគ្រូនៅ **វិទ្យាស្ថានគរុកោសល្យរាជធានីភ្នំពេញ (PTEC)** និង **សាលាគរុកោសល្យ និងវិក្រឹតការខេត្តក្រចេះ (KTPTTC)**។

---

## 🌟 រចនាសម្ព័ន្ធ និងលក្ខណៈពិសេស (Key Features)

### ១. ផ្ទាំងចូលគណនី (Screen 1: Login Screen)

- ចូលគណនីតាមរយៈ អ៊ីមែល និងពាក្យសម្ងាត់ (រួមទាំងប៊ូតុងបង្ហាញ/លាក់ពាក្យសម្ងាត់ `👁 បង្ហាញ`)។
- ជម្រើសចូលគណនីសាកល្បងរហ័ស (1-Click Demo Login)។

  - ព័ត៌មានគណនីគ្រូ `@ sileal.yousohh@gmail.com` និងផ្លាក `👑 Premium`។

- **ប្រអប់ស្វែងរកឆ្លាតវៃ (Real-time Search Filter)**៖ វាយពាក្យគន្លឹះដើម្បីស្វែងរកមុខងារទាំង ២៦ ភ្លាមៗ។

### 🧩 ផ្នែកមុខងារទាំង ៤ ធំៗ (២៦ មុខងារពេញលេញ)

#### ផ្នែកទី១៖ សិស្ស និងវត្តមាន (Students & Attendance)
1. **បញ្ជីព័ត៌មានសិស្ស (Student Info Registry)**៖ មើលព័ត៌មានលម្អិតសិស្ស ភេទ ថ្ងៃកំណើត អាណាព្យាបាល លេខទូរស័ព្ទ និងបន្ថែមសិស្សថ្មី។
2. **បញ្ជីឈ្មោះសិស្ស (Class Roster)**៖ បញ្ជីឈ្មោះតាមលំដាប់លេខកូដ និងភេទ។
3. **ចុះវត្តមានតាមប្លង់ (Seating Plan Attendance)**៖ ប្លង់តុសិស្សបែប Interactive អាចចុចលើតុផ្ទាល់ដើម្បីប្ដូរវត្តមាន (វត្តមាន, ច្បាប់, អវត្តមាន) ជាមួយការរាប់ចំនួនសរុបភ្លាមៗ។
4. **បញ្ជីវត្តមានប្រចាំខែ (Monthly Attendance Sheet)**៖ តារាងសរុបអវត្តមាន និងគណនាភាគរយវត្តមានសិស្សម្នាក់ៗ។

#### ផ្នែកទី២៖ ពិន្ទុ និងការវាយតម្លៃ (Scores & Assessment)
5. **បញ្ចូលពិន្ទុប្រចាំខែ (Monthly Score Entry)**៖ តារាងបញ្ចូលពិន្ទុតាមមុខវិជ្ជា (ខ្មែរ, គណិត, រូប, គីមី, ជីវ, ប្រវត្តិ, អង់គ្លេស...) ជាមួយការគណនាសរុប មធ្យមភាគ និងនិទ្ទេសស្វ័យប្រវត្តិ។
6. **បញ្ជូនពិន្ទុឆមាសទៅអាណាព្យាបាល (Send Scores to Parents)**៖ គំរូសារ Telegram / SMS រួចជាស្រេចសម្រាប់ផ្ញើជូនឪពុកម្តាយសិស្សដោយចុច ១ ឃ្លីក។
7. **បញ្ចូលពិន្ទុ (Quick Score Entry)**៖ កត់ត្រាពិន្ទុកិច្ចការផ្ទះ ឬតេស្តខ្លីៗ។
8. **តារាងពិន្ទុសរុប (Cumulative Score Sheet)**៖ តារាងពិន្ទុឆមាស និងលទ្ធផលសរុប។

#### ផ្នែកទី៣៖ របាយការណ៍ និងស្ថិតិ (Reports & Statistics)
9. **តារាងចំណាត់ថ្នាក់ (Class Ranking Table)**៖ រៀបចំណាត់ថ្នាក់សិស្សពីលេខ ១ ដល់ចុងក្រោយស្វ័យប្រវត្តិតាមមធ្យមភាគពិន្ទុ។
10. **តារាងកិត្តិយស & ប័ណ្ណសរសើរ (Honor Roll & Certificates)**៖ បង្ហាញសិស្សឆ្នើមលេខ ១, ២, ៣ និងមានមុខងារ **បោះពុម្ពប័ណ្ណសរសើរ A4** ផ្លូវការភ្លាមៗ!
11. **បញ្ជីសរុបអវត្តមានប្រចាំឆ្នាំ (Annual Absence Summary)**៖ តាមដានសិស្សដែលមានការឈប់ច្រើន។
12. **កែលម្អសិស្សខ្សោយ (Remedial Action Tracking)**៖ បញ្ជីសិស្សត្រូវការជំនួយបំប៉ន និងផែនការជួយសិស្ស។
13. **កែទម្លាប់អាកប្បកិរិយា (Behavior Tracking)**៖ កត់ត្រាពិន្ទុវិន័យ បូកពិន្ទុសរសើរ ឬដកពិន្ទុព្រមាន។
14. **វិភាគអាយុ និងភេទ (Demographics)**៖ គំនូសតាងស្ថិតិសមាមាត្រសិស្សប្រុស-ស្រី និងកម្រិតអាយុ។

#### ផ្នែកទី៤៖ រដ្ឋបាល និងផ្សេងៗ (Administration & Other Features)
15. **រដ្ឋបាលថ្នាក់រៀន (Class Administration)**៖ រចនាសម្ព័ន្ធគណៈកម្មការថ្នាក់ (ប្រធានថ្នាក់, អនុប្រធាន, បណ្ណារក្ស) និងបទបញ្ជាផ្ទៃក្នុង។
16. **សៀវភៅតាមដាន (Teaching Logbook)**៖ កំណត់ត្រាបង្រៀនប្រចាំថ្ងៃ កាលបរិច្ឆេទ មេរៀន និងកិច្ចការ។
17. **សៀវភៅសិក្សាគោល (Curriculum Books)**៖ បណ្ណាល័យសៀវភៅពុម្ព និងសៀវភៅណែនាំគ្រូ។
18. **ទាញយកវិញ្ញាសាប្រឡង (Exam Papers)**៖ ឃ្លាំងវិញ្ញាសាប្រឡងឆមាស និងតេស្តប្រចាំខែ។
19. **របាយការណ៍អាណាព្យាបាល (Parent Report Card)**៖ របាយការណ៍លទ្ធផលសិក្សាសិស្សម្នាក់ៗ។
20. **លេខកូដសិស្ស (Student Passcodes)**៖ បញ្ជីកូដសម្ងាត់សម្រាប់អាណាព្យាបាលចូលពិនិត្យពិន្ទុតាមទូរស័ព្ទ។
21. **កាលវិភាគសង្ខេបថ្នាក់ (Timetable)**៖ កាលវិភាគប្រចាំសប្ដាហ៍ ចន្ទ ដល់ សៅរ៍។
22. **បញ្ជីសារពើភ័ណ្ឌ (Inventory)**៖ គ្រប់គ្រងតុ កៅអី ក្ដារខៀន កង្ហារ ក្នុងបន្ទប់រៀន។
23. **អត្តសញ្ញាណប័ណ្ណសិស្ស (Student ID Badges)**៖ គំរូប័ណ្ណសម្គាល់ខ្លួនសិស្សមាន Barcode និងរូបថត រួចជាស្រេចសម្រាប់បោះពុម្ព។
24. **ផ្ញើសារទៅអាណាព្យាបាល (Parent Broadcasts)**៖ ផ្សព្វផ្សាយដំណឹង និងកិច្ចប្រជុំ។
25. **សម្ភារឧបទេសផ្ទាល់ (Teaching Aids)**៖ បណ្ណរូបភាព ស្លាយ PowerPoint និងល្បែងសិក្សា។
26. **ព័ត៌មានគណនី (Account Settings)**៖ កំណត់ព័ត៌មានគ្រូ ថ្នាក់ទទួលបន្ទុក និងស្ថាប័ន។

## 🚀 របៀបបើកប្រើប្រាស់ (How to Run & Access)

1. **បើកដោយផ្ទាល់តាម Browser (Local File)**៖
   - គ្រាន់តែចុចទ្វេដង (Double Click) លើឯកសារ `index.html` នៅក្នុង Folder នេះ ដើម្បីបើកដំណើរការភ្លាមៗ។
2. **បើកតាម Web Server ក្នុងម៉ាស៊ីន (Localhost)**៖
   - ចូលទៅកាន់តំណភ្ជាប់ `http://localhost:3000/TeacherGuideApp` ឬ `http://localhost:3000/krusmart`
3. **បើកលើគេហទំព័រផ្សាយផ្ទាល់ (Live Production)**៖
   - ចូលទៅកាន់ `https://ktpttc.net/TeacherGuideApp` ឬ `https://ktpttc.net/krusmart`
