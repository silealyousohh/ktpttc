# 🤖 ការណែនាំប្រព័ន្ធ Telegram Bot សម្រាប់ KTPTTC (KTPTTC Telegram Bot Guide)

ប្រព័ន្ធតេឡេក្រាមបូតផ្លូវការសម្រាប់ **សាលាគរុកោសល្យ និងវិក្រឹតការខេត្តក្រចេះ (Kratie Provincial Teacher Training College - KTPTTC)** ត្រូវបានរៀបចំឡើងយ៉ាងពេញលេញ (Full Integration) ដោយរួមមាន៖
1. **ការជូនដំណឹងសារថ្មីៗភ្លាមៗ (Real-Time Contact Alerts):** នៅពេលមានអ្នកចូលទស្សនាគេហទំព័របំពេញទម្រង់ផ្ញើសារក្នុងទំព័រ Public សារនោះនឹងត្រូវផ្ញើជូនដំណឹងភ្លាមៗទៅកាន់គណនី Telegram ឬ Telegram Group របស់ថ្នាក់ដឹកនាំ/អ្នកគ្រប់គ្រង។
2. **ពាក្យបញ្ជាឆ្លើយឆ្លងឆ្លាតវៃ (Interactive Bot Commands):** អនុញ្ញាតឱ្យសិស្ស និស្សិត គ្រូ និង Admin ពិនិត្យទិន្នន័យ ស្ថិតិ ព័ត៌មាន និងសៀវភៅបណ្ណាល័យដោយផ្ទាល់ក្នុង Telegram។
3. **ដំណើរការពីរទម្រង់ (Dual-Mode):**
   - **Webhook Mode:** ដំណើរការស្វ័យប្រវត្តិតាមរយៈ Cloud Serverless (Vercel) តាមរយៈ Endpoint `POST /api/telegram/webhook`។
   - **Long-Polling Mode:** ដំណើរការលើ Local Development ឬ VPS Server តាមរយៈ `npm run bot`។

## 📋 បញ្ជីពាក្យបញ្ជា Bot (Bot Commands)

| ពាក្យបញ្ជា (Command) | ប៊ូតុងរហ័ស | ការពិពណ៌នា (Description) |
|---|---|---|
| `/start` | - | សារស្វាគមន៍ផ្លូវការ និងបង្ហាញប៊ូតុងមុខងារទាំងអស់ |
| `/status` | 📊 ស្ថានភាពប្រព័ន្ធ | ពិនិត្យស្ថានភាពដំណើរការគេហទំព័រ, MongoDB Atlas, Uptime និងចំនួនអ្នកចូលមើល |
| `/stats` | 📈 ស្ថិតិទូទៅ | មើលស្ថិតិចំនួនសៀវភៅ, បុគ្គលិក, ព័ត៌មាន, វីដេអូ, សារ និងអ្នកទស្សនា |
| `/messages` ឬ `/latest` | 📩 សារពីគេហទំព័រ | មើលសារចុងក្រោយដែលផ្ញើមកពីទម្រង់ទំនាក់ទំនងលើគេហទំព័រ |
| `/news` | 📰 ព័ត៌មានថ្មីៗ | មើលព័ត៌មាន និងសេចក្តីជូនដំណឹងថ្មីៗបំផុតរបស់សាលា |
| `/books [ពាក្យគន្លឹះ]` | 📚 សៀវភៅបណ្ណាល័យ | ស្វែងរក ឬមើលសៀវភៅថ្មីៗក្នុងបណ្ណាល័យឌីជីថល (មានតំណភ្ជាប់អាន PDF) |
| `/id` ឬ `/chatid` | 🆔 Chat ID របស់ខ្ញុំ | មើលលេខសម្គាល់ Telegram Chat ID សម្រាប់យកទៅកំណត់ទទួលដំណឹង |
| `/subscribe` | 🔔 ចុះឈ្មោះទទួលដំណឹង | ចុះឈ្មោះទទួលសារជូនដំណឹងភ្លាមៗដោយមិនបាច់កំណត់ Chat ID |
| `/help` | - | បង្ហាញការណែនាំលម្អិតអំពីរបៀបប្រើប្រាស់បូត |

## 🛠️ របៀបតភ្ជាប់ និងកំណត់រចនាសម្ព័ន្ធ (Setup Instructions)

### ជំហានទី ១៖ បង្កើត Bot ជាមួយ @BotFather លើ Telegram
1. បើកកម្មវិធី **Telegram** រួចស្វែងរកគណនី **[@BotFather](https://t.me/BotFather)** (មានសញ្ញាធីកខៀវផ្ទៀងផ្ទាត់)។
2. ចុច **Start** រួចផ្ញើសារពាក្យបញ្ជា៖
   ```text
   /newbot
   ```
3. @BotFather នឹងសួររកឈ្មោះ Bot៖
   - ឧទាហរណ៍៖ `KTPTTC Assistant` ឬ `សាលាគរុកោសល្យ និងវិក្រឹតការខេត្តក្រចេះ Bot`
4. @BotFather នឹងសួររក Username (ត្រូវតែបញ្ចប់ដោយពាក្យ `bot`)៖
   - ឧទាហរណ៍៖ `ktpttc_bot` (ឬឈ្មោះផ្សេងទៀតប្រសិនបើមានគេប្រើរួច ដូចជា `ktpttc_official_bot`)
5. បន្ទាប់មក @BotFather នឹងផ្ញើ **API Token** ដូចជា៖
   ```text
   7234567890:ABCdefGhIjklmNoPqRstUvWxYz-1234567
   ```

---

### ជំហានទី ២៖ ស្វែងរកលេខ Telegram Chat ID របស់អ្នក
1. ស្វែងរក Bot ដែលអ្នកទើបបង្កើតក្នុង Telegram (ឧទាហរណ៍៖ `@ktpttc_bot`)។
2. ចុចប៊ូតុង **Start** (ឬវាយ `/start`)។
3. ផ្ញើពាក្យបញ្ជា៖
   ```text
   /id
   ```
4. Bot នឹងឆ្លើយតបបង្ហាញលេខ Chat ID របស់អ្នក (ឧ. `987654321`)។

> 💡 **ចំណាំ៖** ប្រសិនបើចង់ឱ្យដំណឹងផ្ញើចូល Telegram Group សូមទាញ Bot បញ្ចូលទៅក្នុង Group នោះ រួចវាយ `/id` ក្នុង Group ដើម្បីទទួលបាន Group Chat ID (ដែលចាប់ផ្តើមដោយសញ្ញាដក ឧ. `-1001234567890`)។

### ជំហានទី ៣៖ កំណត់រចនាសម្ព័ន្ធក្នុងប្រព័ន្ធ KTPTTC

លោកអ្នកអាចជ្រើសរើសវិធីមួយក្នុងចំណោមពីរខាងក្រោម៖

#### វិធីទី១៖ កំណត់តាមរយៈផ្ទាំងគ្រប់គ្រង Admin (ងាយស្រួលបំផុត)
1. ចូលទៅកាន់ Admin Panel របស់គេហទំព័រ៖ `http://localhost:3000/admin` ឬ `https://ktpttc-edu-kh-ll8r.vercel.app/admin`
2. ចូលទៅកាន់ម៉ឺនុយ **ការកំណត់ (Settings)** -> រំកិលចុះក្រោមទៅកាន់កាត **ប្រព័ន្ធ Telegram Bot & ការជូនដំណឹង (Telegram Bot & Real-Time Alerts)**។
3. បិទភ្ជាប់៖
   - **Telegram Bot Token**
   - **Telegram Chat ID**
4. ចុចប៊ូតុង **"រក្សាទុកការកំណត់ Telegram"**។
5. ចុចប៊ូតុង **"ផ្ញើសារសាកល្បង (Test Alert)"** ដើម្បីសាកល្បងផ្ញើសារទៅកាន់ Telegram!

#### វិធីទី២៖ កំណត់ក្នុងឯកសារ `.env`
បើកឯកសារ `.env` ហើយបំពេញ៖
```env
TELEGRAM_BOT_TOKEN=7234567890:ABCdefGhIjklmNoPqRstUvWxYz-1234567
TELEGRAM_CHAT_ID=987654321
```

## 🚀 របៀបដំណើរការបូត (Running the Bot)

### ១. ដំណើរការលើ Local Development ឬ VPS (Polling Mode)
ដំណើរការបញ្ជាខាងក្រោមក្នុង Terminal៖
```bash
npm run bot
```
Bot នឹងភ្ជាប់ទៅកាន់ Telegram និងត្រៀមទទួលបញ្ជាឆ្លើយតបភ្លាមៗ ២៤ ម៉ោងលើ ២៤ ម៉ោង។

### ២. ដំណើរការលើ Vercel Serverless (Webhook Mode)
1. ដាក់ Deploy គម្រោងទៅកាន់ Vercel (`vercel-deploy`)។
2. បន្ថែម Environment Variables ក្នុង Vercel Dashboard Settings:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. ចូលទៅកាន់ Admin Panel -> Settings -> ចុចប៊ូតុង **"កំណត់ Webhook (សម្រាប់ Vercel)"**។
   ប្រព័ន្ធនឹងភ្ជាប់ Telegram Server មកកាន់ `https://ktpttc-edu-kh-ll8r.vercel.app/api/telegram/webhook` ដោយស្វ័យប្រវត្តិ!
