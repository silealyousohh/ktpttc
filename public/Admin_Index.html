ជម្រើសការជូនដំណឹងស្វ័យប្រវត្តិ (Notification Triggers)៖

របៀបបង្កើត និងភ្ជាប់ Telegram Bot ក្នុងរយៈពេល ២ នាទី៖

  1. បើកកម្មវិធី Telegram រួចស្វែងរកឈ្មោះ @BotFather (មានសញ្ញាធីកខៀវ)។
  2. ផ្ញើសារពាក្យបញ្ជា /newbot ទៅកាន់ @BotFather។
  3. បញ្ចូលឈ្មោះ Bot (ឧ. KTPTTC Assistant) រួចបញ្ចូល Username ដែលបញ្ចប់ដោយពាក្យ bot (ឧ. ktpttc_bot)។
  4. @BotFather នឹងផ្ញើ HTTP API Token (ឧ. 7234567890:ABCdef...)។ សូមចម្លង Token នោះមកបិទភ្ជាប់ក្នុងប្រអប់ Telegram Bot Token ខាងលើ។
  5. បើក Bot របស់អ្នក (ចុច Link ដែល BotFather ផ្ញើ ឬស្វែងរកឈ្មោះ Username) រួចចុច Start ឬផ្ញើពាក្យបញ្ជា /id។
  6. ចម្លងលេខកូដ Chat ID ដែល Bot ឆ្លើយតបមកបិទភ្ជាប់ក្នុងប្រអប់ Telegram Chat ID។
  7. ចុច រក្សាទុកការកំណត់ Telegram រួចចុច ផ្ញើសារសាកល្បង (Test Alert) ជាការស្រេច!
💡 ដំណើរការលើ Vercel Cloud: បន្ទាប់ពីដាក់ Deploy សូមចុចប៊ូតុង "កំណត់ Webhook" ដើម្បីឱ្យប្រព័ន្ធ Telegram បញ្ជូនសារមកកាន់គេហទំព័រដោយស្វ័យប្រវត្តិ។
